Kigali Guide Website

Project Description

Kigali Guide is a multi‑page website showcasing things to do and places to eat around Kigali.  
It demonstrates mastery of HTML and CSS fundamentals, including semantic structure, multimedia integration, and responsive design.

Pages Included

- index.html – Home page with navigation, intro, feedback form, video, audio, and embedded Google Map
- memorial.html – Kigali Genocide Memorial page with historical context, images, and table
- park.html – Nyandungu Eco Park page with activities, facilities, and gallery
- convention.html – Kigali Convention Centre page with descriptive text and image gallery
- restaurants.html – Dining guide featuring five popular restaurants with images and captions

Features Demonstrated

- Correct use of HTML tags and semantic structure
- Navigation bar with hover effects across all pages
- At least 10 images with captions
- Internal and external links (e.g., Visit Rwanda tourism site)
- Ordered and unordered lists
- Table for structured information
- Video and audio elements
- Embedded Google Map
- Feedback form with input fields
- CSS styling for layout, images, and hover effects
- Flexbox/Grid for responsive galleries
- Separate CSS file for each page
